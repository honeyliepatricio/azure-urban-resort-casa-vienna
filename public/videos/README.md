# /public/videos

Drop any property walkthrough or hero background video here, e.g.
`public/videos/property-tour.mp4`, reachable at `/videos/property-tour.mp4`.

Example usage in a component:

```jsx
<video autoPlay muted loop playsInline>
  <source src="/videos/property-tour.mp4" type="video/mp4" />
</video>
```
